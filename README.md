#  JetSync - Airline Reservation Management System

A comprehensive, web-based Airline Reservation Management System designed to centralize and streamline essential airline and flight reservation activities. The system provides a secure, structured, and user-friendly platform for both airline administrators and passengers.

##  Features

### For Passengers 
* **Secure Registration & Login:** Create an account and log in securely with JWT authentication.
* **Flight Search:** Search for available flights based on source, destination, and dates.
* **Flight Booking:** Book tickets for different classes (Economy, Business, First Class).
* **Manage Reservations:** View booking history, download tickets, and cancel bookings if necessary.
* **Wallet Management:** Add funds to the digital wallet for seamless booking payments.

### For Administrators 
* **Centralized Dashboard:** A dedicated interface for managing all airline operations.
* **Airplane Management:** Add and maintain records of airplanes and seat capacities.
* **Airport Management:** Register and manage airport details and codes.
* **Flight Scheduling:** Schedule new flights, update statuses, and set seat fares.
* **Reservation Oversight:** View all system-wide passenger booking records.

##  Technology Stack

* **Frontend:** React.js (Vite/CRA), HTML5, CSS3, Bootstrap
* **Backend:** Java, Spring Boot, Spring Data JPA
* **Database:** MySQL
* **Security:** Spring Security, JSON Web Token (JWT), BCrypt Password Hashing
* **API Documentation:** Swagger UI
* **Build Tool:** Maven
